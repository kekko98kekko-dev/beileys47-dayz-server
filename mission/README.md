# Cartella mission/

In questa cartella metteremo **solo copie dei file di missione DayZ attualmente compatibili con Livonia per console** e le nostre modifiche.

Per il momento è volutamente vuota: il file di profilo in `config/` serve soltanto alla progettazione.

Prima di caricare XML/JSON:
1. Recuperare i file corretti della missione del server attivo (o dalla fonte ufficiale nella stessa versione).
2. Conservare copie originali e confrontare le modifiche.
3. Verificare che la mappa attiva corrisponda.
4. Non incollare password e token Nitrado.
5. Eseguire il validatore, poi testare sul server con modifiche incrementali.

**Nota importante:** il passaggio della sintassi XML/JSON non garantisce che DayZ accetti classi, ID di eventi, coordinate e impostazioni; questi controlli richiedono test reali.
