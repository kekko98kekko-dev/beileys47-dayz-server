# Stage 4.2 — ZONA 47 full-footprint proxy clearance

**Status: static screening only; no actual Livonia terrain, road, vegetation, object-volume or PlayStation survey.**

## The limitation that this stage fixes

Stage 4.1 checked the nearest XML terrain and event anchor *to a proposed center*. That is a coarse approximation, especially for a cinematic outpost occupying **240 × 220 metres**.

Stage 4.2 now analyzes the distance between each official mission point and the **nearest edge of an ideal rotated rectangle** representing the planned ZONA 47 footprint. If the point is inside the rectangle, the reported distance is zero.

This is deliberately still **NOT a full collision check**. A terrain group anchor represents one map object reference, not its true 3D shape. A real building can intersect a rectangle without its anchor being inside. Rocks, roads, trees, walls, ponds and terrain slopes are entirely absent from this model.

## Reproducible setup

- Source input: Stage 4.1 source-backed shortlist, itself rebuilt from the pinned official Livonia mission.
- Real DayZ X/Z centers: 9 candidates in 3 regions.
- Ideal planned footprint: **240 m wide × 220 m deep**.
- Rotations: **0°, 30°, 60°, 90°, 120°, 150°** (screening directions only, not actual installed yaw).
- Checks for minimum distances from *footprint edges* to:
  - official terrain-group anchors: **45 m**
  - included **active** dynamic event-position anchors: **180 m**
  - currently selected three fresh-spawn group positions: **1,500 m**.
- Comparison values are internal safety heuristics, **not Bohemia engine requirements or guarantees**.
- For every candidate, report all orientations and a best-scoring passing rotation if one exists. This still does not constitute an approved site or an approved rotation.

## Acceptance and failure

A passing rectangle only indicates that the sampled **XML anchor points** are outside the requested margins. The program writes status **STATIC_ANCHOR_MARGIN_PASSED_SURVEY_NEEDED**. Failure writes **STATIC_ANCHOR_MARGIN_FAILED**.

The site can be authorized for object modeling only after:
1. Checking aerial/topographic reference and **in-game exact parcel**.
2. Confirming no road, forest, water, major prebuilt structure or collision geometry crosses the intended route network.
3. Measuring world Y/terrain slope and a viable yaw angle.
4. Verifying all three attack approaches and two tactical alternatives to the HQ, with PS4 movement performance.
5. Verifying 3–5 objects on the target console build, then expanding only if the test passes.

No pass in this stage may automatically fill the ZONA 47 real-world position in the Object Spawner survey. That survey stays **blank and fail-closed**.
